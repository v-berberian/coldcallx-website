# Your first lead list: a Cold Call X starter file

See how a spreadsheet can become a calling list before you prepare your own data. [Open the sample CSV](sample-leads.csv), or open it in a spreadsheet to inspect its three example rows.

**All records are fictional. Do not call or message them.** The phone numbers use NANPA's reserved, non-working 555-0100–0199 range; the email addresses use `example.com`. This file is for inspecting columns and import results, not testing live calls, texts or emails. It is not a free trial of the app.

## What the columns represent

| Column | Example | Purpose |
|---|---|---|
| `company` | Demo Company One | Company context for the lead |
| `name` | Demo Alex Morgan | The lead's display name |
| `phone` | 2025550101 | Primary phone number |
| `additionalPhones` | 2025550102 | An additional number on the same lead; leave blank if unnecessary |
| `email` | alex@example.com | Email address; leave blank if unnecessary |

The sample includes a lead with one number, leads with an additional number, and a company name containing a comma. CSV quotation marks keep that comma inside one cell.

## If you already have Cold Call X

1. Save the CSV somewhere you can select from your iPhone.
2. Use the app's file-import option to select it. See the existing [Import Your First List tutorial](https://www.youtube.com/watch?v=rqZMEoW6wyE) and [Map Your Columns tutorial](https://www.youtube.com/watch?v=M2wodZdUXZ8) for the app interface.
3. Review the column mapping if prompted: match each field to the corresponding header above. This sample follows the importer’s standard five-column layout; your own file may need a different mapping.
4. Check the imported list before doing anything else. Expect **three leads**, with two phone numbers each for Demo Alex Morgan and Demo Taylor Chen, and one for Demo Jordan Lee. Company names and email addresses should remain attached to the corresponding lead.
5. Delete the fictional list when finished. Do not start a calling session with it.

This checks list preparation and import structure. It does not demonstrate calling, call outcomes, callbacks or follow-ups with real leads.

## Prepare your own list

- Work on a copy of your spreadsheet. Replace every fictional record with your own appropriate lead data.
- Keep phone numbers as text in your spreadsheet so it does not remove leading zeros or change formatting. The sample uses US-format numbers; it is not a universal template for every country's phone format.
- Keep an extra phone number in its own column. Do not make duplicate lead rows just to show a second number.
- Export as CSV and inspect the exported file: names, numbers and email addresses should still be in their intended columns. Review the mapping and a few imported records before calling.
- Check that your intended calls meet the applicable rules. The [calling-hours guide](https://coldcallx.app/blog/calling-hours) is a starting point, not legal advice.

For Google Sheets import, Notes write-back and permissions, use the existing [Google Sheets guide](https://coldcallx.app/blog/google-sheets-dialer). This CSV sample does not establish a live Sheets connection or CRM sync.
