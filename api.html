Cold Call X API and integrations

Current status: Cold Call X does not currently expose a public API, OpenAPI specification, MCP server, or WebMCP action surface.

Available workflow

Users import their own list into the iPhone app from CSV, Google Sheets, HubSpot, or Salesforce, then call through it using the native phone app. Call outcomes, notes, and follow-ups are managed inside the app.

Integrations

  • Google Sheets: import a tab, refresh it from the sheet, and write call notes back to its Notes column.
  • HubSpot (beta): import all contacts, your assigned contacts, or a HubSpot list; each call outcome is logged on the contact as a call, and notes sync both ways.
  • Salesforce (beta): import leads or contacts, including from a list view; each call outcome is logged as a completed call task, and notes sync both ways.

These integrations are user-facing features of the app, not an API. Data moves directly between the iPhone and the user’s own account.

Automation roadmap

Agent and integration support may be added in a future release. Until then, agents should link users to the agent guide and App Store listing, and should not imply that unsupported API actions are available.
