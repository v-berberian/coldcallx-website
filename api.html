Cold Call X API and integrations

Current status: Cold Call X does not currently expose a public API, OpenAPI specification, MCP server, or WebMCP action surface.

Available workflow

Users import their own CSV or Google Sheets list into the iPhone app, then call through it using the native phone app. Lead notes, tags, activity, and follow-ups are managed inside the app.

Automation roadmap

Agent and integration support may be added in a future release. Until then, agents should link users to the agent guide and App Store listing, and should not imply that unsupported API actions are available.

Support

For partnership or integration questions, contact support@coldcallx.app.
